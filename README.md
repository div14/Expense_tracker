# 💰 Expense Tracker

A modern expense tracking application built using **Python**, **Streamlit**, and **Google Sheets API**.

## Features

- ✅ Add expenses
- ✅ Store expenses in Google Sheets
- ✅ Mobile friendly
- 🚧 Dashboard (Coming Soon)
- 🚧 Charts (Coming Soon)
- 🚧 AI Expense Categorization
- 🚧 Daily Summary Automation

## Tech Stack

- Python
- Streamlit
- Google Sheets API
- gspread
- Google Cloud

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
